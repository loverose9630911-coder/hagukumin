# 購買スタートブック（取適法・三菱ふそう・購買の心得）

三菱ふそうトラック・バスの購買に加わる人と同僚が、**スマホだけで**
取適法（中小受託取引適正化法）・会社の歴史・購買の心得を学べる学習アプリです。

> 三菱ふそうトラック・バス株式会社の公式アプリではありません。
> 公的資料・公式発表・報道をもとにまとめた非公式の学習教材です（2026年11月時点で確認）。
> 実務の判断は、社内規程と法務・コンプライアンス部門の指示に従ってください。

---

## できること

| 画面 | 中身 |
|---|---|
| ホーム | 読んだ章の進み具合、「続きから読む」、入社後に確認すること（12項目のチェック） |
| マニュアル | 全13章（取適法7章・ふそう2章・購買4章）。キーワード検索つき |
| クイズ | 4択クイズ（取適法18問・ふそう11問・購買8問から10問出題）、OK・NG のケース判定12問 |
| ツール | 取適法の**対象判定（目安）**、発注前〜支払・記録までの**発注チェックリスト** |
| 用語・出典 | 用語集34語（絞り込み検索）、全出典の一覧（リンクつき） |

- 各章に「**出典で確認済み**」か「**一般的な考え方・社内規程で確認**」かを表示しています
- 確認できなかった数字（工場一覧・従業員数・社内規程など）は載せず、「入社後に確認すること」に回しています
- 記録（読んだ章・チェック・点数）は**その端末の中だけ**に保存されます。サーバーには何も送りません
- 一度ひらけば**電波がなくても**読めます（Service Worker 入り）
- ダークモード対応

## スマホに入れる手順（いちばん簡単な方法）

1. パソコンで <https://app.netlify.com/drop> をひらく
2. この `fuso-kobai` フォルダを、そのままドラッグ＆ドロップする
3. 表示された URL をスマホで開く
   - iPhone：Safari で開く → 共有ボタン → 「ホーム画面に追加」
   - Android：Chrome で開く → 右上のメニュー → 「ホーム画面に追加」（または「アプリをインストール」）
4. ホーム画面のアイコン（クリップボードとトラック）から起動

同僚に配るときは、3 の URL を共有するだけです。

> 社外のサービスに置くことになるため、会社のルールで外部公開が許されるかは事前に確認してください。
> 中身は公開情報だけで作っており、社内情報は入っていません。

## パソコンで確認するとき

```
cd fuso-kobai
python3 -m http.server 8080
```

ブラウザで <http://localhost:8080> を開きます（`index.html` をダブルクリックでも動きますが、オフライン機能は http で開いたときだけ有効です）。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の枠（上部バー・下部タブ） |
| `app.css` | 見た目（色・文字・ライト／ダーク） |
| `app.js` | 画面の切り替え、検索、クイズ、対象判定、チェックの保存 |
| `content.js` | **本文データ**（章・クイズ・ケース・チェック項目・用語・出典） |
| `sw.js` | オフライン用の保存 |
| `manifest.webmanifest` / `img/` | ホーム画面用の名前とアイコン（`img/icon.svg` が元データ） |

## 内容を直すとき

1. `content.js` を編集する（先頭に書き方のルールがあります）
   - 出典で確認した事実は `level: 'verified'` の章に書き、`src` に出典を足す
   - 確認できないことは書かず、`CHECK_LIST`（入社後に確認すること）に入れる
2. `sw.js` の `CACHE = 'kobai-startbook-v1'` の番号を上げる（v2 など）。利用者の端末が新しい内容に入れ替わります
3. もう一度 Netlify Drop にフォルダを置く

## 動作確認（実施済み）

Playwright（Chromium、幅390pxのスマホ表示）で次を確認しました。

- 全13章の表示と横はみ出しなし／ホームで戻るボタンが出ないこと
- 検索（「手形」で5件ヒット → タップで該当章へ移動）
- 「読んだ！」で次の章へ進み、進み具合が増えること
- クイズ（取適法・ふそう・購買を全問正解で100点）、ケース判定（全問正解で100点）
- 対象判定9パターン（資本金基準・従業員基準・個人・全角数字・入力エラー）
- チェックリストが再読み込み後も残ること
- ボタン・タブの高さ44px以上、キーボード操作でフォームが移動すること
- オフラインで再読み込みしても表示されること
- コンソールエラーなし、ダークモードとパソコン幅（1440px）の表示

実機（iPhone／Android）での「ホーム画面に追加」は未確認です。
