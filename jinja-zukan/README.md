# 日本全国 神社図鑑

47都道府県から3社ずつ（計141社）、**ご利益・行き方・歴史・祭事・参拝時間**を1ページにまとめた神社図鑑です。
スマホでも見られる静的な HTML 1枚（＋写真フォルダ）で、サーバーは要りません。

- **都道府県・地方**で絞り込み
- **ご利益**（家庭運・仕事運・金運・縁結び・健康・学業・厄除け・交通安全・勝運・豊作）で絞り込み
- **こんな時に**（結婚・出産／就職・転職・開業／受験／厄年 など）で絞り込み
- 神社を開くと、ご利益・こんな時に・歴史（由緒）・御祭神・行き方（Google マップへのリンク付き）・参拝時間・祭事・出典リンク・写真のクレジットが出ます

## 情報の決まりごと

| 項目 | どこから | 書き方 |
|---|---|---|
| ご利益・御祭神・由緒・行き方・参拝時間・祭事 | 神社の公式サイト（無い場合だけ神社庁・自治体の公式サイト） | 公式に書かれていることだけ。確かめられない項目は空欄、数字は公式に書いてあるときだけ |
| ご利益の分類タグ | 公式のご利益の語句 | `tools/build.py` の表の語が含まれるかで機械的に付ける（ページ下部に表を掲載） |
| こんな時に | 分類タグ | 目安として編集で付けた例（神社の案内ではないとページに明記） |
| 写真 | Wikimedia Commons | 自由利用ライセンスのものだけ。撮影者・ライセンスを各神社の詳細に表示 |

各神社のデータには出典 URL が付いていて、項目ごとにどの出典かをページに表示します。

## ためしかた

| 方法 | 手順 |
|---|---|
| パソコンで | `jinja-zukan/index.html` をダブルクリック |
| スマホで（公開） | <https://app.netlify.com/drop> に `jinja-zukan` フォルダをドラッグ＆ドロップ → 出てきた URL を開く |

## 更新のしかた

```
cd jinja-zukan
python3 tools/build.py --check     # データの検証だけ
python3 tools/fetch_photos.py      # 写真を取り込む（要ネットワーク許可）
python3 tools/build.py             # index.html を作り直す
```

| ファイル | 役割 |
|---|---|
| `data/src/*.json` | 地方ごとの神社データ（形式は `data/SCHEMA.md`）。`sources` が空の神社は「調査待ち」としてページに載せない |
| `data/photos.json` | 写真のファイル・撮影者・ライセンス（`fetch_photos.py` が書く） |
| `data/photo_overrides.json` | 写真を自動で特定できない神社の手動指定（任意） |
| `src/page.html` | ページの本体（見た目と動き）。`build.py` がデータを埋め込んで `index.html` にする |
| `img/` | 写真（960px 幅） |

`fetch_photos.py` は `www.wikidata.org`・`commons.wikimedia.org`・`upload.wikimedia.org` に接続します。
