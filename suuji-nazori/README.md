# すうじと なかまたち（数字なぞりがき＋カウント演出）

ひらがななぞりがきアプリの「さんすう編」です。
数字（1〜10、および 30 などの 2桁）をなぞって書けると、
**その数だけ動物キャラクターがポンポンポンと登場**して、
お子さんの名前（既定：椿來ちゃん）を呼んで褒めてくれます。

「ぞうさんとなかまたち」（`tsumtsum/`）と同じ流儀で作ってあります。

- **静的 HTML＋キャラ画像のみ**（サーバー・外部ライブラリ不要）
- **キャラクターは Gemini で制作したオリジナル動物 7匹**
  （ぞう・うさぎ・カピバラ・キリン・パンダ・ビーバー・こぞう）。
  キャラクター動画のスチルから顔を丸バッジに切り出して `assets/img/ch-*.png` に収録
- **アプリアイコンも同キャラで作成**（こぞうさん＋「1 2 3」。ホーム画面・favicon・PWA用）
- 効果音は WebAudio で合成、声は端末内蔵の日本語音声（音声ファイルなし）
- iPad は **Netlify に置いてホーム画面に追加**するだけ。
  Service Worker（cache-first）入りなので、一度ひらけばオフラインでも動きます

---

## あそびかた

1. メニューで数字をえらぶ（🍎 1〜10 ／ 🌟 11〜30 ／ 🚀 31〜50 ／ 👑 60・70・80・90・100）
2. **みどりの●**から、グレーの道を指でなぞる（お手本の矢印つきの点が動いて教えてくれる）
3. 全部の画が書けたら——なぞった数だけ動物が登場！
   - 1匹ずつ「いち、に、さん…」と数えながらポンポン登場
   - **10匹そろうと「10のまとまり！」**の金色フレームが完成（じゅう！の掛け声つき）
   - 最後に名前を呼んでほめてくれて、紙ふぶき＆ファンファーレ
4. クリアした数字には ★ がつく（3回まで）

⚙「なまえ」から **表示する名前** と **声で呼ぶときの読み**を変えられます
（既定は「椿來／つばき」。読みが違う場合はここで直してください）。

## 実装ステップの解説（同じものを自分のアプリに組み込むには）

コードは `index.html` 内で下の順に並んでいます。ステップごとに独立して移植できます。

### STEP 1. 数字の書き順データ（0〜9 の 10 個だけ作る）

```
DIGITS = { 0:[…], 1:[…], …, 9:[…] }   ← 1桁ぶんのマス（幅100×高さ150）に定義
```

- 各数字は「ストローク（画）の配列」。ストロークは折れ線 `L(...)` と円弧 `A(...)` で書く
- **2桁以上は新しく作らない**のがポイント。`buildNumber(30)` が
  「3のマス」「0のマス」を横に並べてストロークを連結するので、
  **0〜9 さえあれば 30 でも 45 でも 100 でも同じ仕組みでなぞれる**

### STEP 2. なぞり判定エンジン（3歳向けのゆるさ）

各ストロークを 4 単位間隔の点列にリサンプリングし、「いま何点目まで進んだか」だけを見ます。

- 指が道からはみ出しても**減点もリセットもしない**（進まないだけ）
- 指をはなしても、続きの●から再開できる。はじめの●に戻れば書き直しもできる
- 先読み（lookahead）つきなので、多少の飛ばし・ショートカットは許す

ゆるさは冒頭の `CFG` で調整します。

| 定数 | 意味 | 上げると |
|---|---|---|
| `corridor` | 道からの許容はみ出し半径 | かんたんになる |
| `roadW` | 画面に見せる道の太さ（見た目だけ） | 数字が太くなる |
| `startR` | 書きはじめ●の当たり判定 | 置きやすくなる |
| `lookahead` | 先読み点数 | 雑な指でも進む |
| `endSlack` | 終点の手前何点で完成か | 最後が甘くなる |

### STEP 3. 汎用カウントロジック（10の塊）★今回の核心

```js
countPlan(n)  →  { total:23, tens:2, ones:3, groups:[
                    {count:10, animal:ぞう},
                    {count:10, animal:うさぎ},
                    {count: 3, animal:カピバラ} ] }
```

- 描画に依存しない「設計図」を返すだけの純粋関数
- 表示は **テンフレーム（5×2 の 10 マス）** を塊の数だけ並べる
  - マスは常に 10 個描き、埋まっていないマスは点線の○ → 「3 は 10 のうち 3」が見える
  - 10 匹そろった塊は金色フレーム＋「10の まとまり！」ラベルに変わる
  - **塊ごとに動物の種類を変える**ので、23 =「ぞうが10・うさぎが10・カピバラが3」と
    位取りがそのまま目に見える

```
23 の場合：
┏━━━━━━━━━━┓ ┏━━━━━━━━━━┓ ┌╌╌╌╌╌╌╌╌╌╌┐
┃🐘🐘🐘🐘🐘┃ ┃🐰🐰🐰🐰🐰┃ ┆🦫🦫🦫○○┆
┃🐘🐘🐘🐘🐘┃ ┃🐰🐰🐰🐰🐰┃ ┆○○○○○┆
┗━━10のまとまり━┛ ┗━━10のまとまり━┛ └╌╌╌╌╌╌╌╌╌╌┘
```

### STEP 4. 登場シーケンスとほめ演出

`celebrate(n)` が async で 1 匹ずつ進めます。

- 1〜10：ゆっくり（650ms 間隔）、1 匹ごとに「いち、に、さん…」と声で数える
- 11 以上：テンポよく（240ms）、**10 の倍数と最後だけ**声を出す（じゅう！にじゅう！…）
- 10 匹そろうたび効果音＋金フレームの見せ場（550ms）
- 最後に紙ふぶき＋ファンファーレ＋
  「**つばきちゃん、すごい！ ぜんぶで にじゅうさん！ じょうずに かけたね！**」

### STEP 5. 既存のひらがなアプリへの組み込みポイント

- **キャラクターを差し替える**：`ANIMALS` 配列の `img` のパスを変えるだけ
  （正方形の丸バッジPNG・256×256 目安。`img` を省略して `svg:'…'` を入れれば
  コード描画のキャラにもできる。`animalHTML()` がどちらも面倒を見る）
- **ほめ演出を共通化する**：ひらがな側の「なぞり完成」処理から `celebrate(n)` を呼べば
  同じカウント演出が使える。逆に、数字側の完成フック（`strokeDone()` 内の
  `celebrate(tr.model.n)`）を既存の演出関数に差し替えてもよい
- **名前**：`localStorage` の `suuji.name.disp`（表示）と `suuji.name.yomi`（読み）を
  ひらがなアプリと同じキーにそろえると設定が共有できる

### 拡張のしかた

- **数字を足す**：`NUMBERS` を作っているところ（いまは 1〜50 と 60・70・80・90・100）に
  足すだけ。なぞりも 10 の塊も自動で対応（読み上げは 1〜99 と 100 に対応済み）。
  51 以上はカウント間隔が自動で速くなる（`CFG.popMsLots`）
- **3桁**：`buildNumber` はそのまま動く。塊が 10 個を超えるときは
  `sizeSlots()` の 1 行（1段に並べる塊の数）を調整
- **「10のまとまり」を数えさせる**：`countPlan(n).tens / .ones` がそのまま
  「10がいくつ・1がいくつ」なので、次の教材（位取りクイズ）に使えます

## ファイル構成

```
suuji-nazori/
├─ index.html            アプリ本体（画面・なぞり判定・カウント演出）
├─ manifest.webmanifest  PWA設定（ホーム画面の名前とアイコン）
├─ sw.js                 Service Worker（cache-first・オフライン対応）
└─ assets/img/
   ├─ ch-*.png           キャラの丸バッジ 7匹（Gemini制作キャラのスチルから切り出し）
   ├─ apple-touch-icon.png / icon-192.png / icon-512.png   アプリアイコン
   └─ favicon-32.png     ブラウザタブ用（こぞうさんの顔）
```

キャラ画像を差し替えるときは、同名の丸型PNG（透過・256×256 目安）を
`assets/img/` に置き換えるだけです。`sw.js` の `CACHE` 名を `suuji-v2` のように
上げると、公開済みの iPad 側も次回オンライン時に新画像へ入れ替わります。

## 動作確認ずみ

Chromium（Playwright）で指の動きをシミュレートして確認しています。

- 3・8（一筆書きの交差あり）・5（2画）・30（2桁）のなぞり完走
- 3 → ぞう3匹＋空きマス7つ／23 → 金枠2つ＋3匹／30 → 金枠3つ
- キャラ画像（丸バッジ）のメニュー表示とおいわい表示、名前呼び、★保存、JSエラーなし

`window.__nz` にテスト用フック（モデル・座標変換・`celebrate` 直呼び）があります。
