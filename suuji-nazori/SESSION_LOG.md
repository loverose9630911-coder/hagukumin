## 何を作ったか

ひらがななぞりがきアプリ（おなまえおぼえよう）の「さんすう編」。
数字をなぞって書けると、その数だけ動物キャラが「10のまとまり」（テンフレーム）で
登場し、名前（椿來ちゃん）を呼んで褒めるWebアプリ。**Netlifyで公開済み・稼働中**。

- 場所: `suuji-nazori/`（このリポジトリ）
- 方式: 静的HTML＋キャラ画像のみ。外部ライブラリなし。効果音はWebAudio合成、
  声は端末内蔵の日本語音声（Web Speech API）。Service Worker（cache-first）でオフライン動作
- 対象: iPad（ホーム画面に追加してPWAとして使用）

## 主要ロジック（詳細は README.md の STEP1〜5）

- **書き順データ**: 0〜9のストローク定義のみ（幅100×高さ150のマス）。
  `buildNumber(n)` が桁を横に並べて連結するので何桁でもなぞれる（100=3マス3画で確認済み）
- **なぞり判定**: 等間隔リサンプリング＋進行インデックス方式。はみ出し減点なし・
  指を離しても続きから再開。ゆるさは冒頭 `CFG` で調整
- **10のまとまり**: 純関数 `countPlan(n)` → `{tens, ones, groups:[{count, animal}]}`。
  表示はテンフレーム（5×2）を塊の数だけ並べ、空きマスは点線○、10匹で金枠。
  **塊ごとに動物が変わる**ので位取りが目で見える（例: 23 = ぞう10・うさぎ10・カピバラ3）
- **カウント速度**: 1〜10はゆっくり読み上げ、11〜50は240ms間隔、51以上は150ms間隔
  （10の倍数と最後だけ読み上げ）。読みは1〜99＋100（ひゃく）対応

## 運用手順

- **更新のデプロイ**: `suuji-nazori` フォルダを <https://app.netlify.com/drop>
  （既存サイトなら Deploys 画面）にドラッグ＆ドロップ
- **更新を確実に届ける**: 中身を変えたら `sw.js` の `CACHE` 名を上げる
  （v1→v2 は今回実施済み。次は v3）。公開済みiPadは次回オンライン起動時に入れ替わる
- **名前の変更**: アプリ内 ⚙「なまえ」から表示名と読みを変更
  （localStorage: `suuji.name.disp` / `suuji.name.yomi`。既定: 椿來／つばき）
- **判定のゆるさ調整**: `index.html` 冒頭の `CFG`（corridor・startR・lookahead 等）

## 環境の制約（重要）

このClaude Code実行環境からは **Netlifyへの通信が全面的に遮断**されている
（`api.netlify.com` / `app.netlify.com` / `*.netlify.app` すべてプロキシがCONNECT 403）。
そのため:

- デプロイの実行はユーザー側のドラッグ＆ドロップで行う（1分）
- **公開済みのひらがなドリル等（*.netlify.app）のソースもここからは読めない**。
  過去作をClaudeに扱わせたい場合は、①ファイルをチャットにアップロード、または
  ②このGitHubリポジトリにソースを入れる（GitHubは通信可能）のどちらか
