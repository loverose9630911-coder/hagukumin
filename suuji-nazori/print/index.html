おもいでプリント

ホーム画面に追加すると、アプリのようにすぐ開けます
  1. Safari の共有ボタン をタップ（見当たらないときは「…」→「共有」）
  2. 下にスクロールして「ホーム画面に追加」
  3. 右上の「追加」

ブラウザのメニューから「ホーム画面に追加」をえらんでください。

何枚でもまとめて選べます。

  1. 写真をえらぶ（何枚でも・あとから追加もOK）
  2. 用紙・ならべ方・日付をえらぶ
  3. 「じゅんびする」→「プリントする」
  4. 出てきた画面で「プリント」→ プリンターと用紙をえらぶ

写真はこのiPhoneの中だけで処理します。インターネットには送りません。

印刷済みの記録

つかいかた

  1. 「写真をえらぶ」→「写真ライブラリ」から何枚でも選びます。
  2. 用紙・ならべ方・フチ・文字をえらびます。写真をタップすると、切り取る位置や日付を変えられます。
  3. 「じゅんびする」で印刷用の画像を作ります。
  4. 「プリントする」→ 出てきた画面で「プリント」→ プリンターと用紙サイズ（L判など）をえらんでプリント。

はじめて使うとき

プリンターの画面で、写真用紙を入れたカセットの用紙サイズ（L判など）と用紙の種類を登録しておいてください。

まず2〜3枚で試して、次を確かめてください。

  • 「プリント」が出てくるか（出ないときは「画像を保存」→ 写真アプリからプリント、または「ブラウザで印刷」）
  • 用紙サイズにL判などが出るか・写真用紙を入れたカセットから紙が出るか
  • プリントを押したあと、このアプリを閉じても印刷が続くか
  • 横向きの写真が正しい向き・大きさで出るか（小さいときは設定の「よこ写真を たてに回してから送る」）
  • 日付が正しいか（撮影日がわからない写真には日付を入れません）

ホーム画面に追加

Safariの共有ボタン（見当たらないときは「…」→「共有」）→「ホーム画面に追加」→「追加」で、アイコンからアプリのように開けます。

一度開くと画面のファイルをiPhoneに保存するので、次からはすぐ立ち上がり、電波がなくても開けます。新しい版は、次に開いたときに入れかわります。
