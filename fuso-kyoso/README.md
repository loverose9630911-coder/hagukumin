# ふそうバス 競合ウォッチ

三菱ふそうのバス事業の競合（日野・いすゞ・トヨタ・BYDなど）を、出典つきで確認するスマホ向けの画面です。
非公式の調査メモで、三菱ふそうトラック・バス株式会社の公式アプリではありません。

## スマホで使う
- `index.html` は1ファイルです。claude.ai で公開したページ（同じ内容）をスマホで開くのが一番簡単です。
- 画面は下のタブで切り替えます（ホーム・競合・比較・動き・出典）。

## 内容を直す
- `index.html` の `<script>` 内の `MAKERS` / `MODELS` / `EVENTS` / `UNCONFIRMED` / `SOURCES` を書き換えます。
- 状態は `official`（公式発表）/ `report`（報道・出典あり）/ `check`（要確認）/ `none`（未確認）の4種です。
- 数字は出典が確認できたものだけを載せ、推計値や原典未確認の数字は「出典」画面に理由つきで列挙しています。
