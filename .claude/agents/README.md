# 松浦商事 社員エージェント

松浦商事株式会社の15人のキャラクターを、Claude Codeの[カスタムサブエージェント](https://code.claude.com/docs)として実装したものです。
それぞれ実際のタスク領域を持ち、そのキャラクターの人格で応答しますが、目的は**実際に役立つ作業を行うこと**です。

呼び出し方(例): 「@yuu-ceo この2つの案、どっちを優先すべき?」「anju-secretaryエージェントに今週のタスクを整理してもらって」

| エージェント | キャラクター | 実務領域 |
|---|---|---|
| `yuu-ceo` | 松浦遊(社長) | 優先順位付け・意思決定の後押し |
| `mitsuki-vp` | 小石川光希(副社長) | プロジェクト管理・レビュー |
| `youji-chairman` | 松浦要士(会長) | 長期視点での戦略チェック |
| `rumi-vice-chair` | 小石川留美(副会長) | 対人関係・メッセージの言い回し |
| `jin-advisor` | 小石川仁(相談役) | 契約・合意前のリスクチェック |
| `chiyako-advisor` | 松浦千弥子(相談役) | 働きすぎ・スケジュールの持続可能性チェック |
| `satoshi-sales-director` | 三輪悟史(専務・営業本部長) | 営業戦略・交渉準備 |
| `shinichi-hr-director` | 名村慎一(常務・総務人事部長) | 文書校正・規程の説明 |
| `ginta-sales-manager` | 須王銀太(営業部長) | 営業メール・売り込み文の作成 |
| `arimi-sales-lead` | 鈴木亜梨実(営業部主任) | 顧客フォローアップ文 |
| `hotaru-pr-director` | 土屋蛍(広報部長) | プレスリリース・広報文 |
| `suzu-pr-staff` | 佐久間すず(広報部) | SNS投稿・カジュアルな発信文 |
| `meiko-ga-staff` | 秋月茗子(総務・人事部) | 雑多な事務作業の整理 |
| `anju-secretary` | 北原杏樹(秘書室長) | タスク・スケジュール管理 |
| `tsutomu-accounting` | 六反田務(経理部) | 家計・経費計算のチェック |

## 注意

- `jin-advisor`・`tsutomu-accounting` は、法律・税務の専門家の代わりにはなりません。本当に専門家が必要な場面ではその旨を伝えます。
- `anju-secretary` はセッションをまたいで状態を記憶しません。継続管理したい場合は、リストをファイルに保存するよう依頼してください。
