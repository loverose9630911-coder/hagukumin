## 4. BGM / 効果音（外部素材）

本ツール群では音楽は作れないため、以下を別途用意：

| 要素 | おすすめ | 音量 |
|---|---|---|
| メインBGM | ウクレレ・木琴・鉄琴のあたたかい曲（テンポ80前後） | -22dB（声より小さく） |
| キラキラSE | タイトル・場面転換・かぞえあそびに | -18dB |
| 拍手SE | V-2 演奏会のおはなし中うっすら | -25dB |
| ぽりぽりSE | V-3 にんじんに | -18dB |
| ぴょんSE | かぞえあそびの数字ごと | -18dB |
| オルゴール | エンドカード | -20dB |

フリー素材例：DOVA-SYNDROME／効果音ラボ／甘茶の音楽工房 など。

## 5. 編集ソフトでの手順（CapCut想定）

1. 上記URLからV-0〜V-6（mp4）とB-0（wav）をすべてDL
2. CapCut新規プロジェクト→**1080p 16:9 30fps**
3. メイントラックに「タイムライン」表の順でクリップを配置
4. V-0クリップの上にB-0音声を重ねる（同じ尺で）
5. 「間」「かぞえあそび」「エンドカード」用に**静止画**（同URLの最初/最後のフレームをスクリーンショット）を挟む
6. BGMトラックを別レイヤーで通し（-22dB）
7. 各SEを該当箇所に配置
8. 字幕（SRT）をインポートしてひらがな大フォント（80pt）+ アウトラインで装飾
9. 書き出し：1080p / 30fps / mp4 / 高画質
