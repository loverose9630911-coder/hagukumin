# 動物キャラクター擬人化プロジェクト

最初の集合イラスト（10体の動物キャラクター）をベースに、それぞれの外見的特徴・ポーズ・アイテムを
引き継ぎながら「性格」を設定し、個別の擬人化イラスト（計10枚）へと展開したプロジェクトの構成データです。

## 1. プロジェクト概要

| 項目 | 内容 |
|---|---|
| テーマ | 森に暮らす10体の動物キャラクターの擬人化 |
| 出力点数 | 集合イラスト2枚（動物版／擬人化版）＋ 個別擬人化イラスト10枚 |
| 共通設定 | 元イラストの特徴的なアイテム・カラー・ポーズを各キャラに引き継ぐ |
| 舞台 | 草花の咲く明るい森（広場・小道・笹林・お花畑・池のほとり など） |

## 3. キャラクター詳細設定（全10体）

### ① しばお（柴犬）
- **性格設定**: 元気いっぱい、好奇心旺盛な男の子。人懐っこく、誰とでもすぐに仲良くなれる森のムードメーカー。
- **外見・衣装**: 柴犬の耳とくるんとした尻尾。元イラストの赤・オレンジ・黄色のストライプバンダナを首に巻き、オレンジのマウンテンパーカー、デニムパンツ、スニーカーを着用。
- **ポーズ・背景**: 満面の笑みで片手を元気に上げて挨拶している。背景は草花が咲く鮮やかな森の小道。

### ② パン・パン（パンダ）
- **性格設定**: とてもおっとりしていてマイペース。いつも何かを食べていないと落ち着かない、森一番の美食家。
- **外見・衣装**: 少しぽっちゃりした体型の青年。緑色のチャイナテイストのトップス、黒いパンツ、木製のショルダーバッグを着用。
- **ポーズ・背景**: 元のイラストと同様に、お気に入りの笹の茎をのんびり口にくわえている。背景は静かで穏やかな笹林。

### ③ あかね（キツネ）
- **性格設定**: とても利口で、少しいたずら好き。森の噂話に通じており、しばおの良き相談相手。
- **外見・衣装**: スタイリッシュで大人っぽい女性。オレンジのニット、白いシャツ、ブラウンのトラウザー。背中には元のイラストと同じ緑色のリュックサックを背負い、首からカメラを下げている。
- **ポーズ・背景**: ウインクをしながら腰に手を当てている。背景は見晴らしの良い小さな丘の上。

### ④ もも（ウサギ）
- **性格設定**: とても恥ずかしがり屋で、心優しい女の子。お花を育てるのが大好きで、みんなに花束をプレゼントするのが日課。
- **外見・衣装**: 白いウサギの耳。ふんわりとしたクリーム色の花柄ワンピース、サンダル、元のイラストと同じピンクの首元リボン。
- **ポーズ・背景**: 恥ずかしそうに控えめな笑顔を浮かべ、色とりどりの花束を両手で大切そうに抱えている。背景は川が流れる美しいお花畑。

### ⑤ コロマル（ハムスター）
- **性格設定**: とても食いしん坊で、いつも食べ物のことを考えている。ヒマワリの種が宝物で、森の隠し場所に詳しい。
- **外見・衣装**: ぽっちゃりした丸みのある体型の青年。生成りのシャツに、ストライプ柄のカフェエプロンを着用（ポケットにヒマワリの種が入っている）。
- **ポーズ・背景**: 満面の笑みを浮かべ、大きなヒマワリの種を大事そうに両手で持っている。背景は大きなヒマワリが咲くお花畑の片隅。

### ⑥ のん（ナマケモノ）
- **性格設定**: 究極のマイペースで、いつも眠そう。動きはスローだが、実は森の誰よりも深い知識を持っている賢者。
- **外見・衣装**: どこか力の抜けた、とろんとした目の青年。オーバーサイズのゆったりとしたグリーンのタートルネックニット、ブラウンのコーデュロイパンツを着用。頭には葉っぱの冠。
- **ポーズ・背景**: 木の枝に背中を預け、リラックスした様子でぶら下がりながら微笑んでいる。背景は静かで心地よい大きな木の上。

### ⑦ ココ（コアラ）
- **性格設定**: とても寂しがり屋で、誰かにくっついていないと落ち着かない。森の仲間が大好き。
- **外見・衣装**: 大きな耳が特徴的な、少し臆病で守ってあげたくなる雰囲気の女性。白いシンプルなワンピースに、ふんわりとしたブルーのニットカーディガン、ブラウンのブーツを着用。
- **ポーズ・背景**: 大きなユーカリの木の幹に、はにかみながらそっと寄り添い、ユーカリの枝を抱きしめている。背景は陽の光が差し込むユーカリの森。

### ⑧ ミケ（ネコ）
- **性格設定**: 甘えん坊で遊び好き、好奇心旺盛な男の子。森一番の「おしゃれさん」でもある。
- **外見・衣装**: 縞模様の猫耳と長い尻尾。首元には元イラストの赤い首輪とゴールドの鈴。白いシャツにグリーンのケーブルニットベスト、ブラウンのパンツを合わせた動きやすいファッション。
- **ポーズ・背景**: 大きなピンクの毛糸玉を抱え、一本の糸を器用に引き出しながら楽しそうに遊んでいる。背景は明るい陽射しが降り注ぐ森の広場。

### ⑨ ぺんぺん（ペンギン）
- **性格設定**: とても真面目で勤勉、そして少し寒がり。森の気象予報士を目指して毎日勉強中。
- **外見・衣装**: 寒がりなため厚着をした青年。トレードマークである白いポンポン付きの青いニット帽、ボーダーのセーター、ネイビーの厚手ダッフルコート、防寒ブーツを着用。
- **ポーズ・背景**: 片手を上げて真面目に挨拶し、もう片方の手には気象観測用の革表紙のノートと鉛筆を持っている。背景は少しひんやりとした空気感が漂う静かな池のほとり。

### ⑩ くまごろう（クマ）
- **性格設定**: とても力持ちで、心優しい森の守り神。無口だが、困っている仲間がいると一番に手を差し伸べる頼れる存在。
- **外見・衣装**: 大柄でがっしりとした体型の落ち着いた男性。白いケーブルニットセーター、グリーンのハンティングベスト（ダウンベスト風）、ブラウンの頑丈なワークパンツとブーツを着用。
- **ポーズ・背景**: 穏やかで包容力のある笑みを浮かべ、どっしりと腰を落ち着けている。背景は古くから森を見守る「守り神の巨石」と立派な古木の前。

## 4. 制作タイムライン

1. **ステップ1（キャラクター創造）**
   - ユーザーより「動物の可愛らしいキャラクターを10体」とのリクエスト。
   - 森の広場に10体の異なる動物（柴犬・パンダ・キツネ・ウサギ・ハムスター・ナマケモノ・コアラ・ネコ・ペンギン・クマ）が集まる賑やかな1枚の集合イラストを生成。

2. **ステップ2（設定の付与と個別擬人化）**
   - ユーザーより「このキャラクターをベースに擬人化させ、性格を持たせて、一枚ずつの画像に仕上げる」との展開リクエスト。
   - 各キャラクターの名前・性格・衣装・背景のビジョンを定義し、1体ずつ元の特徴を丁寧にサンプリングしながら個別イラスト（全10枚）を出力。

3. **ステップ3（集合擬人化とまとめ）**
   - 最後に、個別に掘り下げた10人の擬人化キャラクターたちが、再び最初の森の広場に集まった「擬人化バージョンの集合イラスト」を生成し、プロジェクトの締めくくりとした。
