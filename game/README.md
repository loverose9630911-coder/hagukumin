# ハグミン ツムツム

オリジナルキャラクター「**ハグミン族**」でつなげて消す、ツムツム系（つなげ消し × 物理積み上げ）のパズルゲームです。
HTML / CSS / JavaScript のみで書かれていて、**外部ライブラリ・画像・音声ファイルを一切使いません**。
キャラクターの絵は Canvas で毎回描き起こし、効果音と BGM は WebAudio でその場で合成しています。

> ディズニーツムツムの版権キャラクター・アセットは一切使用していません。
> 登場キャラクター・名前・スキル・BGM はすべてこのリポジトリ用のオリジナルです。

---

## あそびかた

| ルール | 内容 |
| --- | --- |
| つなぐ | おなじキャラのツムを **3こ以上** なぞってはなすと消える（となり同士のみ） |
| コンボ | つづけて消すとコンボが増え、スコア倍率が最大 2 倍まで上がる |
| ボム | **7こ以上**つなぐとボムが出現。タップで周囲を一気に消す |
| タイムボム | **9こ以上**つなぐとタイムボム。こわすと残り時間 **+5 びょう** |
| スキル | えらんだキャラのツムを消すとゲージがたまり、満タンでスキル発動 |
| フィーバー | ツムを消すと上のゲージがたまり、満タンで 10 秒間スコア 2 倍・時間 +2 びょう |
| 制限時間 | 60 びょう |
| コイン | スコアと最大コンボに応じて入手。新キャラのおむかえに使う |
| レベル | 使うほどキャラの経験値がたまり、Lv.5 までスキルが強化される |

セーブデータ（ハイスコア／コイン／所持キャラ／レベル）はブラウザの localStorage に保存されます。

## 動かしかた

`index.html` を開くだけで遊べます（ビルド不要）。

```bash
# ローカルサーバで開く場合
cd game
python3 -m http.server 8000
# → http://localhost:8000/
```

GitHub Pages に `game/` を公開すれば、そのままスマホのブラウザで遊べます。
`manifest.webmanifest` を同梱しているので「ホーム画面に追加」でフルスクリーンのアプリのように起動します。

対応：スマホ（タッチ）／PC（マウス）。画面比率は 9:16 〜 9:19.5 に自動で収まり、
論理解像度 540 × (960〜1180) にスケールするので、どの端末でも同じ見えかたになります。

## ファイル構成

```
game/
├─ index.html               画面の骨格（タイトル / キャラ選択 / HUD / リザルト）
├─ manifest.webmanifest     ホーム画面に追加したときの設定
├─ icon.svg                 アプリアイコン
├─ css/style.css            UI のスタイル
└─ js/
   ├─ characters.js         キャラ定義・スキル性能・レベルテーブル
   ├─ storage.js            セーブデータ（localStorage）
   ├─ sprites.js            キャラをその場で描くプロシージャル作画
   ├─ audio.js              WebAudio による効果音・BGM 合成
   ├─ physics.js            円の積み上げ物理（位置ベース／PBD）
   ├─ skills.js             7 種類のスキル効果
   ├─ game.js               ゲーム本体（チェーン判定・スコア・演出・描画）
   ├─ ui.js                 画面遷移・HUD 更新
   └─ main.js               起動とボタンの配線
```

### 物理エンジンについて

ツムの山が振動せずにピタッと止まるよう、速度をそのまま積分するのではなく
**位置ベース（PBD）** で解いています。

1. 重力を加えて仮の位置へ動かす
2. めり込みを「位置」で 8 回くり返し解く
3. 実際に動いた距離から速度を作り直す

支えられているツムは位置が動かない ＝ 速度が自動的に 0 になるため、
積み上がった山が完全に静止します（実測 max speed = 0）。
真上に積み重なった「柱」が崩れないのを防ぐため、接触法線がほぼ垂直のときだけ
わずかに横方向へずらしています。

## キャラクターを増やす

`js/characters.js` の `CHARACTERS` に 1 件足すだけで、絵・選択画面・出現ツムまで自動で増えます。

```js
{
  id: 'mint', name: 'ミント', kana: 'つめたい みずのこ',
  color: '#8FE3E0', dark: '#3E9C99', inner: '#DFF7F6', cheek: '#7FD0FF',
  ears: 'round',      // round | pointed | long | horn | none
  eyes: 'sparkle',    // dot | sparkle | sleepy | wink
  mouth: 'smile',     // w | smile | cat | o
  item: 'star',       // none | leaf | star | ribbon | moon | crown
  price: 1500,
  skill: {
    id: 'burst',                        // js/skills.js の効果 ID
    name: 'アイスバースト',
    desc: 'まわりを こおらせて 消す',
    need:  [24, 22, 20, 18, 16],        // Lv1〜5 の必要ツム数
    power: [110, 125, 140, 158, 178]    // Lv1〜5 の効果量
  }
}
```

新しいスキル効果を作る場合は `js/skills.js` の `TABLE` に関数を足し、その key を `skill.id` に指定します。

## ネイティブアプリにしたい場合

このゲームは単体で完結した Web アプリなので、
Capacitor / Cordova などで `game/` をそのまま包めば iOS・Android アプリとして配布できます
（Canvas と WebAudio のみを使っており、追加のネイティブ依存はありません）。
