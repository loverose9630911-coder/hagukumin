## 作業の順番（この順で行ってください）

CSV の販売期間は「11/25 0時から」にしてあるため、**CSV をアップロードした瞬間に、全商品が1円で買える状態になります。** 送料を先に設定しないと、今の送料のまま1円で売れてしまいます。

1. **送料を1点ごとに1,000円にする**（[1. 送料](#1-送料1点ごとに1000円)）
2. **カートで送料を確かめる**（1点で1,000円、2点で2,000円になるか）
3. **商品CSVをアップロードする**（[2. 商品CSV](#2-商品csv価格と販売期間)）
4. **トップページのコードを差し替える**（[4. ストアのトップページ](#4-ストアのトップページ)）
5. **LINE・スレッズに投稿する**（[posts.md](posts.md)）
6. **11/30 17:00 に全商品が買えなくなっているか確かめる**（[3. 終了](#3-終了11月30日月1700)）

## 1. 送料（1点ごとに1,000円）

商品CSVを見てわかったこと ✅
- このストアの送料は、商品ごとの**配送グループ**（CSV の `postage-set` 列）で決まっています。今は 14（40商品）、3（12商品）、4（1商品）、9（1商品）の4つです。
- CSV に**重量の列はありません**。以前この表に書いた「重量を1にして重量別の送料表を作る」方法は、このCSVでは行えません。

やること
- 配送グループの送料の設定画面 ⚠ 要確認：ストアクリエイターPro →「ストア構築」→「カート設定」→「配送方法、送料設定」→ 送料の「編集」

- 送料無料の条件（〇円以上で送料無料など）があれば、セール中は外してください ✅。

## 2. 商品CSV（価格と販売期間）

アップロードするファイル：`csv/data/closing-sale_upload_1yen.csv`（このチャットでもお渡しします。商品データなのでリポジトリには入れていません）

| 列 | 入れた値 | 意味 |
|---|---|---|
| `price` | 1 | 販売価格 1円 ✅ |
| `sale-price` | 空欄 | セール価格を消す（残すと1円より高いセール価格が残り、矛盾するため） |
| `member-price` | 空欄 | 会員価格を消す（同上） |
| `original-price` | 空欄 | 元値を出さない（「元値→1円」の二重価格表示を避けるため） |
| `sale-period-start` | 2026112500 | 販売期間の開始：11月25日 0時 |
| `sale-period-end` | 2026113017 | 販売期間の終了：11月30日 17時 |
| `code` `sub-code` `postage-set` | そのまま | 1文字も変えていません ✅ |

- ファイルの形式は、いただいたCSVと同じです ✅（Shift_JIS、改行は CRLF、列の並びも同じ）。
- アップロードの場所 ⚠ 要確認：ストアクリエイターPro の商品管理から、CSVのアップロード（ダウンロードしたときと同じ「項目指定」の形式）。
- **アップロード後に1商品だけ開いて確認してください。** 販売価格が1円になっているか。セール価格・会員価格・メーカー希望小売価格が空になっているか。販売期間が 11/25〜11/30 になっているか ⚠ 要確認（空欄が「消す」になるか「変えない」になるかは、公式の仕様で確認できていません）。
- いただいたCSVは54商品でした。56商品のうち2商品がCSVに入っていなかった場合、その2商品は変わりません。

CSV を作り直すとき（期間を変えたい場合など）：

```
python3 closing-sale/csv/convert.py 元のCSV.csv 出力.csv --start 2026112500 --end 2026113017
```

書き出す前と後に、変えた列が狙いどおりか、ほかの列が元のままかを自動で確かめます。テストは `python3 -m unittest closing-sale/csv/test_convert.py`。

## 3. 終了（11月30日（月）17:00）

- CSV の販売期間の終了は `2026113017` です。**「17」が「17:00まで」なのか「17:59まで」なのかは確認できていません** ⚠ 要確認。いただいたCSVの以前の終了も同じ形（`2026112217`）でした。
- 確実に17:00で止めるため、**11月30日 17:00 に管理画面で全商品が買えなくなっているかを見て、買えるままなら手作業で非公開にしてください。** スマホのアラームを 16:55 にしておくと安全です。
- 17:00 を過ぎたら、トップページのコードを元に戻してください（元のコードは `toppage/original.html` に保存してあります）。

## 4. ストアのトップページ

差し替えるコード：`toppage/toppage.html`（このチャットでもお渡しします）

- 今のコードから変えたのは2か所だけです ✅（それ以外は1文字も変えていないことを、作るときに自動で確かめています）

## 6. バナー

`out/` フォルダの画像を使います。

| 画像 | 大きさ（px） | 使う場所 |
|---|---|---|
| `out/yahoo-kanban_1180x260.png` | 1180×260 | ストアの看板 |
| `out/line_1040x1040.png` | 1040×1040 | LINE公式アカウントの配信 |
| `out/threads_1080x1350.png` | 1080×1350 | スレッズの投稿 |

- 看板の設定場所 ⚠ 要確認：ストアクリエイターPro の「ストアデザイン」で看板画像を差しかえます。大きさ（横1180×縦260）も外部記事の値です。
- **商品画像（商品ページの写真）には「1円」入りのバナーを使わないでください。** 商品画像に価格などの文字を入れてはいけない、というルールがあると業界記事に書かれています ⚠ 要確認。

### バナーを作り直すとき

```
cd closing-sale/banner
npm install
node render.mjs
```

- `node render.mjs` は、PNG を書き出す前に中身を検査します。検査の内容：決まった文言がすべて入っていること、「15:00」・旧送料「1,500」・旧開始日「11.24 TUE」が残っていないこと、文字がはみ出したり重なったりしていないこと、送料の文字が小さすぎないこと、決めたフォントで描かれていること。1つでも外れたら `out/` には書き出さず、何が問題かを表示します。
- Playwright（Chromium 付き）が入っている環境で動きます。
