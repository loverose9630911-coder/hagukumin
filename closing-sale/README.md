## 2. 販売期間と終了後の非公開

- 終了日時 ✅：**2026年11月30日 17:00**
- 商品ごとの「販売期間」で終了日時を入れられる場合 ⚠ 要確認：終了を `2026/11/30 17:00` にします（CSVの場合はこちらで一括で入れます）。
- 時刻まで指定できない場合：**11月30日 17:00 に手作業で全商品を非公開にします。** スマホのアラームを 16:55 に設定しておくと安全です。
- 17:00 を過ぎたら、ストアのトップから看板バナーも外してください。

## 5. バナー

`out/` フォルダの画像を使います。

| 画像 | 大きさ（px） | 使う場所 |
|---|---|---|
| `out/yahoo-kanban_1180x260.png` | 1180×260 | ストアの看板 |
| `out/line_1040x1040.png` | 1040×1040 | LINE公式アカウントの配信（画像・リッチメッセージ） |
| `out/threads_1080x1350.png` | 1080×1350 | スレッズの投稿 |

- 看板の設定場所 ⚠ 要確認：ストアクリエイターPro の「ストアデザイン」で看板画像を差しかえます。大きさ（横1180×縦260）も外部記事の値です。
- **商品画像（商品ページの写真）には「1円」入りのバナーを使わないでください。** 商品画像に価格などの文字を入れてはいけない、というルールがあると業界記事に書かれています ⚠ 要確認。
- 投稿文は [posts.md](posts.md) にあります。

### バナーを作り直すとき（文言を変えたい場合など）

```
cd closing-sale/banner
npm install
node render.mjs
```

- `node render.mjs` は、PNG を書き出す前に中身を検査します。検査の内容：決まった文言がすべて入っていること、「15:00」や旧送料「1,500」が残っていないこと、文字がはみ出したり重なったりしていないこと、送料の文字が小さすぎないこと、決めたフォントで描かれていること。1つでも外れたら `out/` には書き出さず、何が問題かを表示します。
- Playwright（Chromium 付き）が入っている環境で動きます。
