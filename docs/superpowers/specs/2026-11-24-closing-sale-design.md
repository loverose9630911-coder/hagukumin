# 閉店セール（Office Casual Bura.bura / Yahoo!ショッピング）設計メモ

作成日: 2026-11-24（短い設計メモ。依頼者の回答をそのまま記録したもの）

## 目的と理由
- 閉店にあたり、在庫を売り切るためのセールを行う。
- 依頼者の希望: 商品代金1円、送料1,500円くらい。バナーと金額設定を全体的に用意してほしい。

## 依頼者が決めたこと
| 項目 | 決定内容 |
|---|---|
| 出店先 | Yahoo!ショッピング（ストアクリエイターPro） |
| 対象 | 全商品（56商品・SKUあり） |
| 価格 | 1円 |
| 送料 | 1点ごとに1,000円（案B。2026-11-25 に1,500円から変更） |
| 期間 | 2026-11-25（水）から 2026-11-30（月）17:00 まで（開始日を11-24から訂正） |
| 終了後 | 全商品を非公開 |
| バナーの使い道 | ストアクリエイターPro内（ストア看板）、LINE、スレッズ |
| デザイン | 「オシャレで目立たせて」= 作り手に一任 |
| 送料の実現方法 | 案1: 全商品の重量を1にし、重量別送料表で「1点1,000円、2点2,000円…」とする |
| 一括変更 | 依頼者が商品CSVを送る → 書き換えスクリプトを作る |
| バナー案 | 下記の案で承認済み |

## 方式の検討（Approaches）
- 案1（採用）: 重量欄で点数を数える。まとめ買いでき、1点ごと1,000円になる。店全体の送料表を置きかえる。作れる段数は管理画面で確認が必要。
- 案2（不採用）: 1注文1点まで。購入点数の制限機能がYahooにあるか未確認で、無い場合はキャンセル運用になり揉めやすい。
- 参考（不採用）: 1,001円・送料無料。設定は簡単だが「1円」をうたえない。

## バナー（承認済みの案）
- 配色: 黒×アイボリー。赤は「1円」だけに使う。安売り風にせず、品よく目立たせる。
- 文言: CLOSING SALE ／ 閉店セール ／ 全商品 1円 ／ ＋送料1,000円（1点ごと） ／ 11.25 WED → 11.30 MON 17:00まで ／ 長い間ありがとうございました ／ Office Casual Bura.bura
- 送料は「1円」のすぐ近くに読める大きさで出す（景品表示法の有利誤認を避けるため）。
- 元値（定価→1円）は出さない（二重価格表示の根拠が要るため）。
- 商品画像には「1円」の文字を入れない（商品画像に価格表記を禁じるルールがあるとする業界記事があるため。公式で要確認）。
- サイズ（いずれも外部記事の値で公式未確認）: Yahoo看板 1180×260、LINE 1040×1040、スレッズ 1080×1350。

## 成果物
1. バナーPNG 3種（Yahoo看板・LINE・スレッズ）
2. 設定表（管理画面に入れる値と手順: 価格、重量、送料表、販売期間、商品説明の注意書き、終了後の非公開）
3. LINE・スレッズの投稿文
4. 商品CSV書き換えスクリプト（依頼者のCSVが届いてから、実物の列名に合わせて作成し、実行テストしてから渡す）

## 作り手に任されたこと
- フォント、レイアウト、細かな配色、投稿文の文面。

## 未確認のこと（設定表に「要確認」として残す）
- 重量別送料表で作れる段数。段数を超える注文の扱い（商品説明に「1回の注文は〇点まで」と書く）。
- 1円・高めの送料が Yahoo のガイドラインに触れないか（禁止条文は見つからなかった）。
- 手数料が送料を含む金額にかかるか。
- 販売期間を時刻（17:00）で指定できるか。
