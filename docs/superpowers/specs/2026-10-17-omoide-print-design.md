# おもいでプリント 設計書（方向性の決定を含む）

- 日付: 2026-10-17
- 置き場所: `suuji-nazori/print/`（Netlify の既存サイトの `/print/` で公開）
- 状態: 実装済み（このブランチ）。iPhone 実機での確認は未実施

---

## 1. 困りごと（ユーザーから聞いた事実）

- iPhone の写真アプリで写真を選び、EPSON のアプリで用紙サイズを選んで印刷している
- 手間と時間がかかる
- EPSON のアプリで一度に印刷できるのは 20 枚まで
- 印刷中は EPSON アプリの画面を開いたままにしておく必要がある
- 子どもの写真が多い
- プリンターは EPSON **EW-M873T**、使っているアプリは **Epson Smart Panel**、よく使う用紙は **L判**（2026-10-17 に回答）

## 2. 方向性の決定

| 案 | 判定 | 理由 |
|---|---|---|
| ① 写真アプリと EPSON アプリを自動でつなぐハブアプリ | **作らない** | iOS では、あるアプリから別のアプリの画面を自動操作できない。EPSON Smart Panel が iOS のショートカットに対応しているという情報は見つからなかった（下の出典）。つないでも EPSON アプリ側の 20 枚制限と「開いたまま」は残る |
| ② 別の写真印刷アプリ | **採用** | EPSON アプリを通さず、iPhone 標準のプリント機能（AirPrint）に直接わたす。20 枚制限と「開いたまま」は EPSON アプリ側の制約なので、経路ごと外す |

②の作り方は **Web アプリ（ホーム画面に追加して使う PWA）** にする。

- このリポジトリの他のアプリ（すうじ・ひらがな）と同じ作り方・同じ公開先で、追加費用なし
- iPhone 専用アプリ（App Store 型）は Mac・Xcode・Apple の開発者登録が必要で、この環境では作れず試せない
- 写真は iPhone の中（ブラウザの中）だけで処理し、どこにも送らない。子どもの写真なので、サーバーに上げない作りを優先した

### 調べてわかった事実（出典）

- iPhone のプリント中は、アプリ切り替え画面に「プリントセンター」が現れ、進行状況の確認とキャンセルができる
  （[Apple: iPhoneからプリントする](https://support.apple.com/en-bn/guide/iphone/iph92628b8f/ios)、
  [キヤノン: AirPrint の説明](https://ij.manual.canon/ij/webmanual/Portal/S/JP/AFG/afg_appleairprint.html)）
- 最近の iOS の AirPrint は、プリンターに設定された用紙サイズを選択肢に出す、という回答がある
  （[Apple コミュニティ](https://discussionsjapan.apple.com/thread/254728472)）
- Safari の Web 共有で画像ファイルを渡したとき「プリント」「画像を保存」が出なくなる不具合があり、2023 年に修正された記録がある
  （[WebKit Bug 255641](https://bugs.webkit.org/show_bug.cgi?id=255641)）
- CSS の `@page { size }` は iOS Safari 18.2 から対応という互換表がある（WebKit の公式発表では未確認）
  （[MDN @page size](https://developer.mozilla.org/en-US/docs/Web/CSS/@page/size)）
- EPSON Smart Panel がショートカットに対応しているという情報は見つからなかった
  （[App Store: Epson Smart Panel](https://apps.apple.com/app/id1477796092)）

### 調べてもわからなかったこと（実機での確認が必要）

1. iPhone 標準のプリントで一度に送れる枚数に上限があるか
2. 「プリント」を押したあと、元のアプリを閉じても印刷が続くか
   （プリントセンターが別に動くことは事実だが、閉じてよいと書いた公式文書は見つけていない）
3. このアプリから共有シートを開いたとき「プリント」が出るか（iOS のバージョンによる）
4. 横向きの写真を L 判に送ったとき、iOS が自動で向きを回すか
5. 写真の撮影日（EXIF）が、iPhone の写真選択画面を通したあとも残っているか
6. ~~お使いの EPSON プリンターが AirPrint に対応しているか~~ → 対応（下の「EW-M873T について」）

アプリはこの 6 点のどれがダメでも使い続けられるように、逃げ道を用意してある（5 章）。

### EW-M873T について（調べた事実と、確認が必要なこと）

- AirPrint: EPSON 公式の「iOS端末からのプリント（AirPrint）」の対応機種に EW-M873T が載っている
  （[エプソン: AirPrint](https://www.epson.jp/connect/ext/airprint/)）。
  ※ この環境からは epson.jp の本文を直接開けず、検索結果の要約で確認した
- 給紙: 前面2段カセット。上段は L判〜B6・最大20枚、下段は L判〜A4・最大100枚という紹介記事がある
  （[週刊アスキー](https://weekly.ascii.jp/elem/000/004/037/4037193/)）。
  写真用紙の正確なセット枚数は取扱説明書の表で**確認が必要**
- 用紙の登録: カセットを入れたときの画面で用紙サイズと種類を登録できる
  （[EW-M873T ユーザーズガイド: 用紙サイズと種類の登録](https://download4.epson.biz/sec_pubs/ew-m873t_series/useg/ja/GUID-0BD7680A-C5B2-428D-BFCB-2B09DB56A919.htm)）
- 気をつけること: 「スマホから印刷すると背面給紙が選ばれて印刷できない」「給紙が自動だと下段が優先される」という利用者の書き込みがある
  （[価格.com 掲示板1](https://bbs.kakaku.com/bbs/K0001299356/SortID=26297092/)、[価格.com 掲示板2](https://bbs.kakaku.com/bbs/K0001299356/SortID=24748957/#24748957)）。
  AirPrint でどのカセットから出るかは**実機で確認が必要**
- 上段カセットが20枚までなら、L判を21枚以上まとめて送ると途中で用紙の補充が必要になる見込み。
  補充したあと続きが印刷されるかは**確認が必要**

## 3. アプリでできること

| 機能 | 内容 |
|---|---|
| 写真をまとめて選ぶ | iPhone の写真選択画面で何枚でも選べる。あとから追加もできる |
| 用紙に合わせて切り取る | L判・KG・はがき・2L判・A4。「フチなし（切り取る）」「フチあり（ぜんぶ入れる）」。1 枚ずつ指でずらす・拡大・回転できる |
| 1 枚に 2 面・4 面 | 用紙の節約や、連絡帳に貼る小さい写真に |
| 日付と年齢を入れる | 撮影日（EXIF）から「'26 5 5」「つばき 3さい1かげつ」を写真の右下に入れる。きょうだい 4 人まで。撮影日がわからない写真には入れない（ウソの日付は入れない）。写真を自動で回したときは文字も回し、写真を正しい向きで見たときの右下に来るようにする。写真の幅に入りきらない行は小さくする |
| 似ている写真をまとめる | 連写などで似た写真に同じ色の印をつけ、いちばんくっきりした 1 枚に★。ボタン 1 回で他をはずせる。形（dHash）と色合い（4×4 の平均色）の両方が近いときだけ「似ている」とする（空・壁など模様の少ない写真どうしを取りちがえないため） |
| 印刷済みの記録 | 印刷した写真を iPhone の中に記録し、次に選んだとき「印刷済み」と出す。ボタン 1 回ではずせる |
| 枚数指定 | 1 枚の写真を 2 枚ずつなど |
| プリント | 共有シートの「プリント」（iPhone 標準のプリント）に全部まとめて渡す |
| 分けて送る | うまくいかないときや、EPSON アプリに渡すときのために「20 枚ずつ」などに分けられる |

## 4. しくみ

```
写真選択（iPhone）──> 読み込み（縮小版・撮影日・似ている度・くっきり度）
                           │
                  画面で確認・調整（切り取り位置・枚数・日付）
                           │
           ［プリントのじゅんび］用紙サイズちょうどの JPEG を作る（300dpi）
                           │
           ［プリントする］共有シート ──> プリント（AirPrint）
                                     └─> 画像を保存 / 他のアプリ（予備）
           ［ブラウザで印刷］Safari の印刷（@page で用紙サイズ指定。予備）
```

- `core.js`: 画面に依存しない計算（用紙・マス割り・切り取り・回転・年齢・EXIF 読み取り・似ている判定・くっきり度）。Node でテストする
- `app.js`: 画面の操作と描画
- 共有（`navigator.share`）はボタンを押した直後でないと iOS が受け付けないため、
  「じゅんび」と「プリントする」の 2 回に分けている
- 設定と印刷済みの記録は端末の `localStorage` だけに保存する

## 5. 逃げ道（実機で問題が出たとき）

| 問題 | 逃げ道 |
|---|---|
| 共有シートに「プリント」が出ない | 「画像を保存」で写真アプリに保存 → 写真アプリからプリント。または「ブラウザで印刷」 |
| 一度に送れる枚数に上限があった | 設定「まとめて送る枚数」を 50 / 20 / 10 枚に |
| 横向きの写真が小さく印刷される | 設定「よこ写真を たてに回してから送る」をオン |
| AirPrint 非対応のプリンター | 共有シートに EPSON アプリが出ればそこへ渡す（出るかは確認が必要）。出なければ「画像を保存」→ EPSON アプリで選ぶ。設定を「20 枚ずつ」にすると EPSON アプリの上限に合わせて分けられる。切り取りと日付入れの手間は減るが、20 枚制限と「開いたまま」は残る |

## 6. 今後の方向性

1. **いま**: このアプリを iPhone で 2〜3 枚だけ試し、2 章の 6 点を確認する
2. **確認の結果で直す**: 6 点の結果に合わせて初期設定を変える（例: 横写真の向き、まとめて送る枚数）
3. **必要になったら**: 共有シートを通さずに直接プリントしたい、プリンターと用紙を毎回固定したい、
   という段階になったら iPhone 専用アプリ（Swift の `UIPrintInteractionController`）を検討する。
   Mac と Apple の開発者登録が必要（費用は最新の公式情報で確認が必要）

## 7. テスト
