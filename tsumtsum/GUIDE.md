# ぞうさんとなかまたち ― つかいかたメモ

娘さんの iPad で遊ぶための、**あとから見返す用のメモ**です。
コードの中身の説明は [README.md](README.md) にあります。

---

## これは何

自作の動物キャラクター **6匹（ぞう・うさぎ・カピバラ・キリン・パンダ・ビーバー）** で
つなげて消す、ツムツム系のパズルゲームです。

- アプリアイコンは **ぞうさん**
- 画面の文字は全部ひらがな
- 画像・音の素材ファイルは持たず、その場で描いて・鳴らしています
- ゲームのルールは **Python**、Web アプリは **PHP** で書いています

---

## いまの公開状態

| | |
| --- | --- |
| 置き場所 | Netlify（GitHub 連携） |
| 公開しているフォルダ | `tsumtsum/dist/` |
| 設定ファイル | リポジトリ直下の `netlify.toml`（さわらなくて大丈夫） |

| セーブ | その iPad の中だけ（コイン・所持キャラ・レベル・ハイスコア） |

### iPad に入れる（もう済んでいますが、別の端末に入れるとき用）

1. **Safari** で Netlify の URL を開く（Chrome だとホーム画面に追加できません）
2. **共有ボタン ↑** をタップ
3. **「ホーム画面に追加」** → 「追加」

## 中身を変えたときの手順

```bash
cd tsumtsum
make static                      # dist/ を作りなおす
git add -A
git commit -m "なにを変えたか"
git push
```

push すると Netlify が自動で更新します。
**iPad 側は、アプリを一度閉じて開きなおす**と新しくなります。

> それでも古いままなら、ホーム画面のアイコンを削除して、
> Safari で開きなおして追加しなおしてください。

## よくある調整

### むずかしさを変える

`engine/zousan/` の中の数字を変えて、`make static` → push します。

| 変えたいこと | ファイル | 変えるところ | 今の値 |
| --- | --- | --- | --- |
| 制限時間 | `rules.py` | `PLAY_TIME` | 60 びょう |
| コンボが切れるまで | `rules.py` | `COMBO_HOLD` | 2.2 びょう |
| フィーバーの入りやすさ | `rules.py` | `FEVER_NEED`（小さいほど入りやすい） | 55 |
| フィーバーの長さ | `rules.py` | `FEVER_TIME` | 10 びょう |
| コインの入りやすさ | `rules.py` | `COIN_PER_SCORE`（小さいほど貯まる） | 120 |
| ボムになる数 | `board.py` | `BOMB_CHAIN` / `TIME_BOMB_CHAIN` | 7こ / 9こ |
| ツムの数（多いほどやさしい） | `board.py` | `target_count()` の `0.52` | 画面の下半分 |
| ツムの大きさ | `board.py` | `TSUM_R` | 34 |

小さいお子さん向けにやさしくするなら、
**制限時間を長く（90 びょう）** ＋ **`FEVER_NEED` を小さく（35 くらい）** が効きます。

### キャラクターを増やす

`engine/zousan/characters.py` に 1 件足すだけです。
絵もキャラ選択画面も出現するツムも、自動で増えます。

```python
Character(
    id="kuma", name="くまさん", tagline="もりの ともだち",
    kind="beaver",              # 絵の描きかたの種類
    body="#C08A5A", shade="#7A5230", inner="#EBD3B6",
    cheek="#FF9C9C", accent="#E8C98A", price=2000,
    skill=Skill(id="burst", name="はちみつバースト", desc="まるく 消す",
                need=[24, 22, 20, 18, 16], power=[110, 126, 142, 160, 180]),
)
```

```bash
make assets && make static     # 絵を描きなおして dist/ も作りなおす
```

`kind` に使えるもの: `elephant` / `rabbit` / `capybara` / `giraffe` / `panda` / `beaver`
`skill.id` に使えるもの: `burst`（円） / `rainbow`（よこ） / `wave`（たて） / `cross`（十字） / `ramune`（ランダム＋時間） / `dam`（大ツム化）

まったく新しい見た目にしたいときは `tools/render_assets.php` の `drawByKind()` に、
新しいスキルは `engine/zousan/skills.py` の `TABLE` に足します。

### キャラの色だけ変える

`characters.py` の `body`（本体）/ `shade`（輪郭）/ `inner`（耳の内側）/
`cheek`（ほっぺ）/ `accent`（帽子など）を変えて `make assets`。

## 困ったとき

| こまりごと | みるところ |
| --- | --- |
| Netlify で画面が真っ白 | 公開フォルダが `tsumtsum/dist` になっているか（`netlify.toml` が指定します） |
| 更新が iPad に反映されない | アプリを閉じて開きなおす → だめならアイコンを削除して追加しなおす |
| 音が出ない | 画面を一度タップ（iOS は最初のタップまで音が出せません）／右上の ♪ ボタン／本体のサイレントスイッチ |
| ホーム画面に追加が出ない | Chrome ではなく **Safari** で開いてください |
| セーブを消したい | Safari の「履歴とWebサイトデータを消去」。※ゲーム内にリセット機能は付けていません（必要なら足せます） |

## つくったときに詰まったところ（記録）

あとで似たものを作るときのために残しておきます。

**ツムの山が永久にプルプル震えた**
速度をそのまま積分すると、支えられたツムに重力が溜まりつづけます。
「重力で仮の位置へ動かす → めり込みを位置で解く → 動いた距離から速度を作り直す」
という**位置ベース（PBD）**の順にしたら、支えられたツムの速度が自動的に 0 になって止まりました。

**ツムが宙に浮いたまま固まった**
静止の判定を「全方向の速さ」で見ていたため、山の横ゆれがおさまらず、
まだ落下中のツムをその位置で固めていました（盤面の 15%）。
判定を **下向きの速さだけ**に変え、さらに「どこにも触れていないツムがいたら着地するまで回す」
仕上げを足して 0% にしました。

**Python だと物理が遅かった（1手 100ms 超）**
(1) 止まったツムを計算から外す、(2) ぶつかりそうな組み合わせを 1 ステップに 1 回だけ作る、
(3) 接触面の摩擦を入れて転がりを止める、の 3 つで **1手 39ms** になりました。

**「ゲームスタート」を押してから 1.7 秒待たされた**
画面の外からツムを落として積んでいたのが原因。
最初から六角形に敷きつめて軽くゆらす方式に変え、さらにタイトル表示中に裏で作るようにして解消。
